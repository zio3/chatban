# デモ板の初期状態 (seed)

`scripts/reset-demo.mjs` がここの `.db` を `data/` へ戻す。

**中身 (`.db`) はリポジトリに入れない。**`*.db` は gitignore してあるし (#194)、
初期状態は環境ごとに違ってよいものなので、**動かしている場所に置く**
(公開デモなら VPS の `backend/seed/`)。このディレクトリは置き場所の予約。

- **ここが空なら「空の板」に戻る**
- 初期状態を決めるときは、板を実際に作ってから `node scripts/reset-demo.mjs --snapshot` で採る
- `-wal` / `-shm` は採らない — 整合が取れているのは `.db` 側で、副産物を混ぜると差し替えのときに壊れる
