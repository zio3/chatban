## 1. 課題: Done増えすぎ問題

AIワーカーがアサイニーとして参加すると、完了速度が人間の数倍になり、Done列が急速に肥大する。従来のかんばんは「人間が1日に数枚終える」前提の分量設計なので、この前提が崩れる。

二律背反が本質:

- **表示からは消したい** — 列が縦に伸びてボード全体の見通しが落ちる。デモ映えとしても「達成感」ではなく「散らかった感じ」になる
- **コンテキストからは消したくない** — 完了履歴は割り振りレコメンドと受領ブリーフィングの学習材料そのもの。消すとプロダクトの芯が痩せる

既存ツール（Trelloのアーカイブ、Jiraのクローズ、vibe-kanban系）は「人間の視界から消す」ことだけが目的で、消した後そのデータがAIに使われる想定がない。ChatBanでは完了履歴が機能の材料なので、同じ設計は使えない。

## 2. 解法: アーカイブ + 要約常駐

**生ログはアーカイブへ、蒸留した知識は現役のまま残す。** 記憶の階層構造と同じ。

- 完了タスクは一定条件で `archived` にし、**AIのコンテキスト構築対象から外す**
- アーカイブ時にAIが要約カードを生成し、**要約はボードに常駐する**（コンテキストにも含める）
- 常駐コストは要約分だけに抑えられる

### 要約カードの要素分解とチェック

要約は単一テキストではなく**要素の配列**として持つ。各要素に「確認済み」チェックを付ける。

```
[要約カード] 8/9午前の完了 (6件)
  ☑ 認証周りを高橋が3件対応。#12でセッション管理の方針をJWTに決定
  ☐ UIコンポーネントをClaudeが2件追加（マークダウンレンダリング、常時表示化）
  ☑ OrcaRouter接続検証完了、コスト計測ログを整備
```

これがかんばんとの決定的な差別化になる。かんばんのDoneは「作業が終わった」を表すが、AIが完了させたタスクの本当の関心事は「**人間がその内容を把握したか**」。列を動かすメタファーでは表現できない粒度で、「かんばんから違う体験に寄せる」の実例になる。

結果として、Doneは増えるほど散らかる列から、**増えるほど要約が育つ場所**に反転する。

### 要約に何を書くか（設計の勘所）

要約の目的は「短くすること」ではなく「**後で参照する価値のある形に凝縮すること**」。

- ❌ 「5件完了」 — 単なる件数表示、材料にならない
- ⭕ 「認証周りを高橋が3件、UIをClaudeが2件。#12でセッション管理の方針をJWTに決定」 — **決定事項と担当の偏り**が残り、割り振りレコメンドと受領ブリーフィングの材料としてそのまま使える

## 3. LLMの使い所（審査項目⑥の題材）

同じ機能の中でルーティングが2種類走るので、実測比較の題材として最適。

| 処理 | 性質 | ルーティング |
|---|---|---|
| 要素分解（何を独立した確認単位として切り出すか） | 判断寄り | 品質優先 |
| 要約文生成 | 定型処理 | コスト優先 |

「アーカイブ要約1回あたり○円、内訳は分解が○円・要約が○円」と実測原価を提示できる。

副次的に⑦セキュリティにも効く。「会話とタスクの全履歴を毎回LLMに送っているのか?」に対し「いいえ、古い完了は要約して送っています」と答えられる。

## 4. 実装タスク（Claude Code向け）

1. **アーカイブのデータ構造** — 生タスクは `archived` フラグ、要約カードは常駐エンティティ（子タスクIDの配列 + 要素配列 + 統計）
2. **要約生成** — 要素分解（品質優先モデル）+ 要約文生成（コスト優先モデル）、**コスト計測を最初から組み込む**
3. **要約カードUI** — 要素リスト + 要素ごとのチェックボックス + 展開/折りたたみ
4. **AIコンテキスト構築の変更** — `archived` は除外、要約カードは含める（※地味だが必須。忘れると設計の意味がなくなる）

### スコープ制限（7日制約）

- **チェック状態を起点にした挙動変化は作らない**。状態機械が複雑化し、リアルタイム同期の沼に近づく
- 「未確認が3件あります」程度の**表示**は軽いので可
- 今回は「畳む・常駐する・チェックできる」の3点で閉じる

## 5. デモ・記事での使いどころ

- **デモ**: 「今日8件終わったんだけど」と打つと、Done列の8枚がスッと1枚のサマリーカードに畳まれる。画面上で情報が整理される瞬間は映像として効く
- **過去への窓**: 「先週の認証の話って誰がやったんだっけ」→ チャットで聞けばAIが要約から答える。ボードだけのツールには作れない体験
- **⑧次世代性**: vibe-kanban / KittyClaw / is.team 系は完了カードをただ積むだけ。要約して畳む挙動は競合調査範囲内で該当なし
