# デモ板の初期状態 (seed)

`scripts/reset-demo.mjs` がここの `.db` を `data/` へ戻す。

- **ここが空なら「空の板」に戻る。**いまの公開デモはこれ (触った跡を全部消す)
- サンプルのカードを置いておきたくなったら、板を作ってから
  `node scripts/reset-demo.mjs --snapshot` で採る

`backend/data/` はドッグフーディングの実録なので、**そのまま seed にしない**
(リポジトリは公開されている)。`-wal` / `-shm` は採らない — 整合が取れているのは `.db` 側で、
副産物を混ぜると差し替えのときに壊れる。
